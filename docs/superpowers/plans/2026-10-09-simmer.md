# Simmer Implementation Plan

**Goal:** Ship Simmer (Tauri v2 cookbook, desktop + Android) and its recipe feed repo, both public and copyleft, with automatic recipe sync.

**Architecture:** `simmer-recipes` compiles YAML recipes into a content-addressed static feed on `gh-pages`. `simmer` is a React/TS app whose pure `domain/` and `sync/` layers are unit tested, with `platform/` wrappers that fall back to web APIs so the whole app runs under Playwright.

**Tech stack:** Tauri 2, React 19, TypeScript, Vite, Motion, MiniSearch, Zustand, idb, Zod, Vitest, Testing Library, Playwright. Recipes repo: Node 20, yaml, Ajv, sharp.

**Spec:** `docs/superpowers/specs/2026-10-09-simmer-design.md`

## Global constraints

- Feed schema major version: `1`, served under `v1/`.
- Mirrors, in order: `https://cheerslovedani.github.io/simmer-recipes/v1/`, `https://raw.githubusercontent.com/CheersLoveDani/simmer-recipes/gh-pages/v1/`.
- Wide layout breakpoint: 820px.
- Bundle-vs-delta threshold: more than 20 changed recipes, or first sync, fetches the bundle.
- Auto-sync interval: 6 hours.
- Licences: app AGPL-3.0-or-later; recipe content CC BY-SA 4.0; recipe tooling AGPL-3.0-or-later.
- All motion respects `prefers-reduced-motion` and the in-app setting.

## Review focus

1. Sync interrupted midway (network drops after manifest) — previous recipes stay intact and usable.
2. A feed recipe that fails validation — skipped, others still applied.
3. Scaling odd quantities (0.333 cup × 1.5, "to taste", ranges) — readable fractions, no `NaN`/`0`.
4. User data pointing at a recipe the feed later removed (favourite, plan slot, shopping source) — no crash, entry shown as unavailable or dropped.
5. Search input with punctuation, accents, or only whitespace — no throw, sensible results.

## Shared interfaces

```ts
// domain/schema.ts
type Unit = 'g'|'kg'|'ml'|'l'|'tsp'|'tbsp'|'cup'|'oz'|'lb'|'pinch'|'clove'|'sprig'
          |'slice'|'can'|'bunch'|'stick'|'leaf'|'handful'|'piece'|null
type Aisle = 'produce'|'meat-fish'|'dairy-eggs'|'bakery'|'pantry'|'spices'
           |'tins-jars'|'frozen'|'drinks'|'other'
interface Ingredient { qty: number|null; qtyMax?: number; unit: Unit; item: string;
  key: string; aisle: Aisle; prep?: string; note?: string; optional?: boolean; fixed?: boolean }
interface Step { text: string; timer?: { minutes: number; label: string }; tip?: string }
interface Recipe { id: string; hash: string; title: string; description: string;
  course: Course; cuisine: string; tags: string[]; diet: Diet[]; difficulty: Difficulty;
  serves: number; yield?: string; time: { prep: number; cook: number; rest: number; total: number };
  ingredients: { section: string|null; items: Ingredient[] }[]; steps: Step[];
  equipment: string[]; tips: string[]; substitutions: { for: string; use: string; note?: string }[];
  storage?: string; nutrition?: Nutrition; cover: { hue: number; motif: string };
  image?: string; author: string; created: string; updated?: string }
interface Manifest { schemaVersion: number; revision: string; generatedAt: string;
  bundle: { path: string; hash: string; bytes: number };
  recipes: { id: string; hash: string; path: string }[];
  images: { id: string; hash: string; path: string }[] }

// sync/sync.ts
interface SyncResult { status: 'up-to-date'|'updated'|'unsupported'|'failed';
  added: string[]; updated: string[]; removed: string[]; skipped: string[]; error?: string }
function syncRecipes(deps: { fetch: typeof fetch; store: RecipeStore; mirrors: string[] }): Promise<SyncResult>

// store/recipeStore.ts
interface RecipeStore { all(): Promise<Recipe[]>; revision(): Promise<string|null>;
  hashes(): Promise<Map<string,string>>;
  apply(c: { put: Recipe[]; remove: string[]; revision: string }): Promise<void> }
```
